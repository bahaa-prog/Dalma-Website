# مدينة الدلما الإنسانية — React Site

Next.js (App Router) + TypeScript rebuild of the institutional website. See **[CLAUDE.md](./CLAUDE.md)**
for full project context: structure, conventions, the news/jobs data model, and open decisions
(hosting, jobs-form backend).

## Commands

```bash
npm run dev     # http://localhost:3000
npm run build   # static export -> out/
npm run start   # serve the built out/ folder locally (static export, no Node server)
npm run lint
```
